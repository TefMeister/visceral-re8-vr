# Hand poses

Our own Hand Poser finger poses for Village (not game data: Euler angles per finger joint, made by us or by Tefa in the Hand
Poser window). The live set is in the game's `reframework/data/hand_poser/guns/` and the window's own folder; the generator
is `../native/tools/make_rest_poses.py`.

- `archive/2026-11-05-before-rest-poses/`: all 66 files as they were before the game's own resting poses replaced the copies.
