# Visceral VR — Resident Evil Village

**Public since 2026-10-24; work started 2026-10-15. Unfinished, and it may cause motion sickness.** Andyalpa's "Hands Off" pack for Resident Evil Village (holsters,
recoil, hand gestures, haptics, ammo HUD, drop physics) is being ported to C++ as Visceral RE8, the same way
[visceral-re2-vr](https://github.com/TefMeister/visceral-re2-vr) is built. Since 2026-10-18 it also has manual reloads
(magazines, single shells, slide / bolt / pump racking with the left hand on the gun), moved over from the parked
Visceral RE7. Since 2026-10-24 every story-mode gun has been surveyed in the game (its moving parts and its own
sounds), so the hand reloads reach them all. Nothing is ready to play yet.
